# Khu vườn Những Người Bạn — bộ nhân vật (Mùa 1)

Nguồn duy nhất cho hình dạng nhân vật. Mọi tập phim import `characters.js`, nên nhân vật luôn giống hệt nhau.

- `characters.js` — `CAST` (tên, màu, phụ kiện) và `drawCharacter(ctx, id, pose)`; pose: `face` = smile | happy | sad | wow, `wave` 0..1, `wob`, `blink`.
- `sheets/` — model sheet đã duyệt.
- `engine/` — engine style Mid-century Cartoon, lấy từ lemomo-ai/lemo-opuscar (MIT).
- `fonts/` — Lobster, Baloo 2 (SIL OFL), hỗ trợ tiếng Việt.

ID: tho (Thỏ Trắng), soc (Sóc Nâu), gau (Gấu Xám), meo (Mèo Mun), nhim (Nhím Nâu), cu (Cô Cú), de (Thầy Dê), ho (Hổ Béo).
Mỗi tập dùng 3–4 nhân vật.
