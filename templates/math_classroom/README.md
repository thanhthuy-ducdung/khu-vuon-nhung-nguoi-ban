# Mẫu tập toán: lớp học Mid-century + bảng phấn + bàn tay đếm
Dựng từ tập "Ô vuông bí mật". Dùng lại cho các tập toán sau: chỉ thay `problems()` (đề, dòng đổi phép tính, câu giơ tay/đếm/đáp án),
`DIALOGUE`, tiêu đề và câu bài học; cần thêm `sentences.json`, `env.json`, `subs_en.json`, `counts.json` (mốc từng chữ đếm) và `voice.mp3` của tập mới.
- Bảng phấn: font `fonts/PatrickHand.ttf` (OFL), ô vuông phấn cam, viết từng phần, lau bảng giữa các bài.
- Bàn tay: `../../hands.js`, gập/giơ ngón đúng lúc đọc "trừ 1, trừ 2…" / "cộng 1…".
